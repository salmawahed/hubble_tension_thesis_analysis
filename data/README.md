# Data
 
The Pantheon+SH0ES dataset is publicly available from the SH0ES team.
 
## Download
 
Go to the official data release repository:
 
https://github.com/PantheonPlusSH0ES/DataRelease
 
Download the following two files and place them in the **root directory**
of this repository (same folder as `run_analysis.py`):
 
```
Pantheon+SH0ES_data.dat
Pantheon+SH0ES_STAT+SYS.cov
```
 
## File descriptions
 
| File | Size | Description |
|------|------|-------------|
| `Pantheon+SH0ES_data.dat` | ~2 MB | 1701 supernovae with redshifts, distance moduli, and diagonal errors |
| `Pantheon+SH0ES_STAT+SYS.cov` | ~23 MB | Full 1701x1701 systematic covariance matrix |
